# Installation

## Prerequisites

Windows users **MUST** have SH in order to use the run.sh and run-nogui.sh scripts.
To do so you can use busybox to emulate sh easily:
```
scoop install busybox
```

# From source

to use the [pull paper jar script](), you must first install jq. You can do so easily using
```sh
brew install jq
```
change the variable VERSION with the version you want to pull.
